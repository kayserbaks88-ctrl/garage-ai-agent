Frequently asked questions

What businesses usually ask.

What is TrimTech PayChaser?

PayChaser is an AI-assisted credit-control app. It brings customers and invoices into one dashboard, prepares payment-request emails, adds a secure payment option and tracks the remaining balance.

Can I review a chase message before it is sent?

Yes. The subject and message are shown for review and can be edited before sending. The secure payment button is then added automatically.

Does PayChaser work with Xero and Stripe?

Yes. The current workflow can retrieve customer and sales-invoice data from Xero and use Stripe for secure customer payments.

Can Garage AI actually book appointments?

Yes. Garage AI can check live availability and create an appointment using the services and booking rules configured for that garage.

Does Garage AI work differently for each garage?

Yes. Each garage can have its own name, greeting, services, pricing, opening hours, calendar, phone number and operational data.

Can I see the products before deciding?

Yes. Request a free demonstration and select the product you want to see. We will walk through the working system rather than only showing presentation slides.
